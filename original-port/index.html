    Abrir ejecutor Java ME ↗

    Compatibilidad no garantizada: algunos MIDlets necesitan ajustes de teléfono, resolución, sonido o teclas. En iPhone, si el emulador no carga o el juego falla, eso no significa que el JAR esté dañado.

    Este ejecutor es una alternativa externa basada en FreeJ2ME, no forma parte del port nativo. Nuestro port propio aún no ejecuta bytecode Java ni tiene misiones jugables.

    Estado real del port

    El arranque del navegador y la lectura local del contenedor JAR están preparados. El juego completo todavía no es jugable: falta decodificar los sprites y mapas, portar la lógica Java original, implementar colisiones, enemigos, armas, audio y misiones, y compararlo con el juego de referencia.

    Esta página no finge ejecutar el juego. Mostrar el splash y detectar recursos confirma la lectura del archivo, pero no equivale a tener una misión funcional.
    Código fuente del port · La página no contiene ni distribuye el JAR comercial.
