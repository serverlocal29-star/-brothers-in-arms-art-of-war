Misión de combate

Reconstrucción web jugable con 13 misiones, tres campañas, armas, granadas, enemigos, controles táctiles y guardado local. No es una conversión fiel del juego Java original.

PC: WASD/flechas para moverte · ratón para apuntar · clic/espacio disparar · R recargar · G granada · 1/2/3 cambiar arma · P/Esc pausa.

Móvil: joystick izquierdo y botones de disparo, recarga, granada y arma.

Mando: stick izquierdo o cruceta para moverte · stick derecho para apuntar · A disparar · B granada · X recargar · Y cambiar arma · LB/RB cambiar arma · Start pausar.

Conecta un mando compatible antes o durante la partida.

Proyecto comunitario no oficial, no afiliado a Ubisoft ni Gameloft.
