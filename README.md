# STAR — Brothers in Arms: Art of War

Experimental browser launcher for testing Java ME games.

- Responsive STAR landing page.
- FreeJ2ME Web included as a Git submodule in `emulator/`.
- Emulator loads only after pressing START.
- Select your own JAR in the emulator. The website does not upload it to GitHub.

## Status
This is an emulator launcher, not a completed native port. Compatibility of Brothers in Arms: Art of War has not yet been verified. The commercial JAR is intentionally not included in this public repository.

Upstream emulator: https://github.com/zb3/freej2me-web

FreeJ2ME Web currently relies on CheerpJ and requires internet access. See upstream documentation and licensing.
